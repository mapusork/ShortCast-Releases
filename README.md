# ShortCast — Releases
- **Ürün:**  YouTube 7/24 canlı yayın yöneticisi
- **Son sürüm:** sağ taraftaki **Releases** sekmesinden indirin.

## Kurulum

1. Sağdaki **Releases** sekmesinden en son `ShortCast-Setup-X.Y.Z.exe` dosyasını indirin.
2. Çift tıklayarak kurulumu başlatın (Windows "Bilinmeyen yayıncı" uyarısı için **Yine de çalıştır** deyin).
3. Uygulamayı açın, lisans kodunuzu girin, yönetici hesabını oluşturun.

## Otomatik güncelleme

ShortCast açıldığında bu repodaki son sürümü kontrol eder ve yeni sürüm varsa otomatik indirir/uygular.
